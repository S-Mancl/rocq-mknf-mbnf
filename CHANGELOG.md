# Changelog

## 0.1.0 — 2026-11-10

First packaged release of the MKNF/MBNF formalization.

- Propositional syntax and finite-world semantics for MKNF and MBNF.
- Verified entailment and countermodel procedures, including Rosati's partition algorithms.
- A worked murder mystery example.

Requires Rocq 9.1 and rocq-stdlib 9.0. Imports use the `MKNF` namespace.
